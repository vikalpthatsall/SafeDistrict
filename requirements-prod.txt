# index rather than plain PyPI. Verified: plain `torch==2.11.0` resolves to a
# ~530MB manylinux wheel with CUDA bundled in; download.pytorch.org/whl/cpu
# publishes the same 2.11.0 version as a ~190MB CPU-only build (`+cpu`).
# --extra-index-url (not --index-url) so other packages still resolve from
# PyPI normally.
